→ Filter Data Flow

Global Filter System
4 filters in useFilters.js are shared across all views via Vue's composition API singleton pattern. Each view watches the filter refs and reloads data on change.
Time Period
YYYY-MM or Q1/Q2/Q3/Q4-YYYY
Used by: orders, dashboard
Warehouse
San Francisco · London · Tokyo
Used by: inventory, orders, dashboard
Category
Circuit Boards · Sensors · Actuators · Controllers · Power Supplies
Used by: inventory, orders, dashboard
Order Status
Delivered · Shipped · Processing · Backordered
Used by: orders, dashboard
Note: Inventory filters do not support Time Period (no time dimension on stock data).
1
User changes a filter in FilterBar.vue
v-model="selectedPeriod" (or warehouse/category/status) updates the ref in useFilters.js — a singleton composable shared across all views.
2
Watcher in the current view fires
Each view declares watch([selectedPeriod, selectedLocation, selectedCategory, selectedStatus], loadData). The load function runs immediately.
3
getCurrentFilters() maps state to query params
useFilters.getCurrentFilters() returns { warehouse, category, status, month }, mapping UI labels (e.g. "location") to API param names. Values of 'all' are omitted.
4
api.js sends HTTP GET with query string
e.g. GET /api/orders?warehouse=Tokyo&category=sensors&month=2025-01. Axios serializes the params object automatically.
5
FastAPI applies filters sequentially
apply_filters() does exact warehouse match, case-insensitive category/status match, then filter_by_month() handles both direct month strings and quarter ranges (Q1-2025 → Jan/Feb/Mar).
6
Pydantic validates and Vue updates
Response is validated against the Pydantic model, serialized to JSON, and returned. The view stores it in a ref(); computed properties (KPIs, charts, tables) recalculate automatically.

◆ Key Patterns & Notes

Reactivity Model

Raw data in refs, derived in computed
Views hold allOrders, inventoryItems etc. as raw ref([]). KPIs, charts, table rows are computed properties — no manual refresh needed.

Inventory Search

Client-side only
Inventory name search in Inventory.vue filters the already-loaded array client-side via computed. No API call is made on keypress.

Data Persistence

None — in-memory only
Backend loads JSON at startup into Python lists. Any write (e.g. create PO) exists only in-memory and is lost on server restart.

Quarter Filtering

Mapped server-side
filter_by_month() translates Q1-2025 → ["2025-01", "2025-02", "2025-03"] and matches against order_date ISO strings.

Internationalisation

EN / JA + USD / JPY
useI18n.js composable provides t(key) lookup and formatCurrency(). Language toggle in header switches all labels live.

Purchase Orders

Frontend ready, backend missing
POST /api/purchase-orders is called by the modal but the endpoint is not in main.py. The Pydantic model and data file exist; endpoint just needs to be wired up.
